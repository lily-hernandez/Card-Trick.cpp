♠️♦️ Card Trick – Interactive C++ Terminal Program ♣️♥️

🎩 Overview

This is an interactive C++ command-line program that performs a mind-reading card trick.
You secretly choose a card — and through a series of prompts —
the program guesses your card correctly 

This project demonstrates:

-C++ fundamentals

-Control flow & loops

-Algorithmic thinking

-Terminal / CLI interaction

-Logic & deduction
